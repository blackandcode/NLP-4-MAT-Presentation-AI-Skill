# Privacy

**4MAT Presentation Studio** (`nlp-4-mat`) is a set of instruction files (skills and agent prompts), reference documents and small local Python scripts.

- **No data collection by this project.** The plugin contains no servers, no MCP connectors, no analytics, no telemetry and no network calls. The bundled scripts (`audit_deck.py`, `render_deck.py`) read and write only the local files you point them at.
- **Your content stays where you work.** Briefs, claim ledgers, scripts and decks are written as files in your own workspace, or in the AI host's sandbox when you use claude.ai or ChatGPT.
- **The AI host processes your conversation.** When you use these skills in Claude (claude.ai, Claude Desktop, Cowork, Claude Code), ChatGPT or Codex, your messages and uploaded files are handled by that provider under its own privacy policy and your account settings. This project has no access to them.
- **Personal stories**: the skills ask before using any personal experience in a presentation, and never invent one.

Questions: open an issue at https://github.com/blackandcode/NLP-4-MAT-Presentation-AI-Skill/issues.
