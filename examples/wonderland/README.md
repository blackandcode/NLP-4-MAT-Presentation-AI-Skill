# Worked example: Wonderland NLP Master defense

Example audience: NLP Master trainers/examiners. Total duration: 15 minutes. Medium: slides plus spoken explanation with optional live demo. Language: English for this repository demonstration (the original project manuscript was written in a South Slavic language and may be delivered in that language instead).

The presentation intentionally emphasizes the abstract educational strategy more than the game. Wonder Creator is a *demonstration*, Disney's strategy is one method of structuring creative exploration, and a meaningful assessment of children's learning is still future work.

Run:

```sh
python ../../scripts/audit_deck.py presentation.json --strict
python ../../scripts/render_deck.py presentation.json --out presentation.html
```

Files: `presentation.json` (editable machine-readable deck); `presentation.html` (generated preview); `speaker-notes.md` (generated script); `evidence.md` (sourced claim ledger). The example includes a live-demo fallback but **does not** connect to the Wonderland site or claim to validate its current availability.

**Suggested alternate narrative:** For educators/parents, lead with child agency and the robot/turtle example. For investors, lead with a verified audience problem and propose a pilot request, without inventing commercial traction or impact.
