# Presentation workspace contract

Create `outputs/<slug>/` (or `examples/<slug>/`) in a user-approved folder. Preserve these filenames for predictable handoffs across the `4-mat-to-nlp-presentation` suite:

- `brief.md`: purpose; audience; present state; desired observable audience behavior; duration; language; medium; narrative ratio (e.g., **70% personal journey / 30% NLP model** when blending personal story with methodology); constraints; speaker preference; decisions and assumptions.
- `nlp-pocket-analysis.md`: structured output from the composable NLP pocket skills (`4mat-perceptual-positions`, `4mat-disney-strategy`, `4mat-logical-levels`, `4mat-sleight-of-mouth`, `4mat-nested-loops`, `4mat-state-anchor`)—capturing 1st/2nd/3rd/4th Perceptual Positions, Dreamer/Realist/Critic cycle, Dilts Logical Levels alignment, LIFO Nested Loops, and Stage Psychogeography map.
- `evidence.md`: claim ID (`C001`, etc.), exact claim, evidence link and page/line, status (`SOURCE` / `INTERPRETATION` / `PROPOSAL` / `HYPOTHESIS` / `UNVERIFIED`); counterevidence and claim-safe wording.
- `storyboard.md`: section ID, phase, optional eight-step lens, estimated minutes, personal-to-model weave ratio, central insight, proof, audience activity, narrative transition, intended response and Why re-anchor.
- `script.md`: actual spoken words synchronized with separate presenter process cues (Stage Anchor zone, Satir posture, Gesture, Loop open/close, VAKOG emphasis, and Tonal inflection).
- `slides.json` / `presentation.json`: data used by renderer; include exact `duration_minutes`, `slides` array with `phase`, `minutes`, `title`, `headline`, `body`, `speaker_notes`, and optional `evidence_ids`, `visual`, `audience_prompt`, `process_notes`, `diagram` (type `steps`, `cycle`, `layers` or `roadmap`; 2–6 labeled nodes).
- `presentation.html`, `speaker-notes.md`: generated by `scripts/render_deck.py`.
- `qa.md`: audience-specific questions, skeptic questions, Sleight of Mouth reframes, candid evidence/limitations, and answers.
- `review.md`: scores, blockers, recommended revisions, user approval status and unresolved questions.

## Non-negotiable gates

- Before drafting: missing outcome, audience, medium, duration, or personal-vs-model blend ratio → ask or explicitly mark user-chosen assumption.
- Before locking WHY and WHAT IF on a complex or emotional topic: run or offer the composable NLP pocket exercises (`4mat-perceptual-positions`, `4mat-disney-strategy`, `4mat-logical-levels`).
- Before presenting facts: evidence verification and claim ledger (`4mat-evidence`).
- Before generating final visuals: approve storyboard direction (`4mat-storyboard`).
- Before completion: run deterministic rubric / timing checks (`scripts/audit_deck.py`) and editorial review (`4mat-review`).

## Example slide schema

```json
{
  "title": "A meaningful project title",
  "audience": "Precisely who is listening",
  "duration_minutes": 15,
  "language": "sr-Latn-ME",
  "medium": "slides+speech",
  "slides": [
    {
      "phase": "mini-what",
      "minutes": 0.5,
      "title": "What we'll explore",
      "headline": "One clear preview",
      "body": ["Concise, accessible support"],
      "speaker_notes": "Opening script",
      "process_notes": "[STAGE: Center | SATIR: Leveller]",
      "evidence_ids": ["C001"]
    }
  ]
}
```

The production renderer supports `mini-what`, `why`, `what`, `how`, `what-if`. All five are required in order. Use numerically positive durations that sum to `duration_minutes`.
