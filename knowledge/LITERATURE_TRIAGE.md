# Audit of 58 citations appearing in the supplied research synthesis

> **Method:** This is an *inventory and credibility triage*, not a claim that all 58 external full texts were read or individually verified. The synthesis contains 58 numbered works-cited entries. It also contains large embedded images, excluded from this text index. Original OCR and Wonderland manuscript were read locally. External spot-checks focused on 4MAT primary/publisher pages, learning-style evidence, official Claude/Gemini/OpenAI tooling, and NLP systematic-review literature.

## Priority and interpretation

- **Core theory / candidate empirical studies:** original 4MAT/McCarthy, experiential learning, studies of 4MAT outcomes. Any effectiveness claim requires full-text appraisal, not a landing-page abstract.
- **Practitioner/marketing:** useful for vocabulary, exercises and the history of the NLP training tradition; should not independently substantiate neurological or educational effects.
- **Secondary/mirror:** contextual examples at best; avoid unverified and potentially copyrighted downloads.
- **Tooling:** secondary posts are replaced with current **official** Claude Code and Agent Skills platform documentation.
- **LLM retrieval research:** may help software document ingestion but does not establish an equivalence to human attention curves or validate 4MAT.
- **Clear mismatch:** reference 23 relates to fractional heat equations, not presentation psychology.

## Corrections that materially affect this repository

1. **4MAT is first a useful design sequence** (meaning, concept, practice, transfer). Descriptions of percentages of fixed audience types are not verified population estimates.
2. **Hemispheric mapping in the supplied report is a claim of the historical framework.** This package does not teach or assert functional brain lateralization as a neuroscience fact.
3. **NLP presuppositions, covert commands and psychogeography do not have evidence here for bypassing conscious judgment.** The skills use transparent storytelling, ethical rapport, precise questions and explicit choices instead.
4. **Human attention and LLM context placement are different questions.** The synthesis blends them as analogy; the software implements source chunking because traceability and manageable context improve reliability, without claiming neuroscientific equivalence.
5. **Source hierarchy:** prioritize supplied original handout for what a course teaches; original author/publisher for 4MAT terms; relevant primary studies for effectiveness; official docs for tool behavior; skeptical systematic reviews for controversial broad claims.
