# Claude Code instructions — 4MAT NLP Skills

For any task to design, adapt, rehearse, audit, or render a 4MAT presentation, start from the skill `/4mat-start` or an appropriate narrower skill.
Use the project files under `skills/`, `agents/` and `knowledge/` when available.
When tools permit, use AskUserQuestion for interactive single-/multi-choice decisions. Never assume that a question tool is present.
Parallel agents can research and critique independently, but must not make irreversible decisions for the user. Review all agent disagreements in the main conversation.
Source claims in the academic example must distinguish an existing early prototype, a future vision, and untested research hypotheses.
