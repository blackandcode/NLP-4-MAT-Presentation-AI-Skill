# Rehearsal / defense loop

Use the approved script and target medium. First summarize one-page cues per phase: Preview; Relevance; Theory; Demonstration; Future/Next-step. Offer a rehearsal mode: (A) timed full run, (B) difficult examiner/investor Q&A, (C) opening and closing only, (D) live-demo failure simulation.

For a written environment without audio or stopwatch, **do not claim to have measured live speaking performance**. Estimate speech minutes using stated WPM assumption (default 120–150 wpm, adjust for language) and separately account for demonstration / pause / Q&A. Ask actual audience questions one by one, wait for response, provide respectful, evidence-grounded feedback, then retry.

Suggested hard Wonderland academic questions: "What is modeled vs merely illustrated?", "What can the current prototype actually do?", "Where is evidence of creativity improvement?", "Why NLP rather than a conventional educational model?", "How is child agency and privacy protected?", "How would you design a pilot with parental consent?". Avoid presenting expected results as measured outcomes.

Recommend short, optional confidence routines and honest audience check-ins. In a pitch rehearse the financial/strategic ask and 'what if no' decision. End with concrete practice priorities and unresolved claims—not hollow cheerleading.
